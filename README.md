# Satır Arası

Okuduğun kitabın paragrafına göre arka planda müzik çalan okuma uygulaması.

## Çalıştırma

```bash
node server.js
```

Sonra Chrome veya Edge'de http://localhost:4173 adresini aç.

## Testler

```bash
node tests/run.js && node tests/data.test.js && node tests/engine-room.test.js && node tests/keywords.test.js && node tests/lang.test.js
```
